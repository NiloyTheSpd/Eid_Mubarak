# Eid Mubarak Terminal Animation

A fun Python terminal script that simulates an Arch Linux-style package install flow and reveals an animated **Eid Mubarak** message.

## Features

- Boot-style startup logs
- Interactive mirror selection
- Animated download/progress simulation
- Key-mash “decryption” mini-game
- Final Eid Mubarak ASCII-art reveal

## Requirements

- Python 3.8+
- A terminal that supports ANSI colors

## Run

```bash
python3 eid_arch.py
curl -fsSL https://raw.githubusercontent.com/NiloyTheSpd/Eid_Mubarak/main/eid_arch.py | python3
```
